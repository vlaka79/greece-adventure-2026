# Daniel & Julia’s Greece Adventure 2026

A public trip site for friends and family — Crete, Santorini, and Athens.

**Live:** https://djboone-travels.netlify.app/

**Repo:** https://github.com/vlaka79/greece-adventure-2026

This folder *is* the site. No install, no Node build.

## Netlify

If this repo is already imported, a push to `main` republishes automatically.

First-time import:

1. Open [Netlify](https://app.netlify.com) → **Add new site → Import an existing project**
2. Choose **GitHub** → **`vlaka79/greece-adventure-2026`**
3. Build command: leave empty (`netlify.toml` handles it)
4. Publish directory: `.`
5. Deploy
